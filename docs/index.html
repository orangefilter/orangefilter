Frequently Asked Questions

Everything you need to know about The Orange Filter.

Is The Orange Filter free?

Yes, The Orange Filter is completely free to use. There are no premium tiers, subscriptions, or hidden costs. The source code is open source and available on GitHub.

Does it collect my data?

No. The Orange Filter runs 100% offline on your device. It collects zero data, uses no analytics, and never transmits anything to external servers. All processing — including AI image analysis — happens locally in your browser.

How does the AI image detection work?

The extension uses TensorFlow.js to run a machine learning model directly in your browser. When you visit a page, the AI analyzes images locally on your device in real-time to identify political content and blurs matching images. No images ever leave your computer.

Which browsers are supported?

The Orange Filter currently supports Google Chrome (and Chromium-based browsers like Brave and Edge). Firefox support is planned for a future release.

Can I whitelist specific websites?

Yes. The Orange Filter includes a whitelist feature that lets you disable filtering on specific websites. This is useful for sites where you want to see all content unfiltered, or for sites that don't work well with the filter enabled.

How do I install it?

Download the zip file from this page, extract it to a folder on your computer, then open chrome://extensions in Chrome, enable "Developer mode" in the top right corner, click "Load unpacked", and select the extracted folder. The filter starts working immediately on all new pages you visit.

Will it slow down my browser?

The Orange Filter is designed to be lightweight. The text filtering is near-instantaneous, and the AI image processing runs in an isolated background worker to avoid affecting page performance. Most users report no noticeable slowdown.

What permissions does the extension need?

The extension requires: storage (to save your settings locally), activeTab (to know which site you're on for whitelist functionality), scripting (to inject the content filter), declarativeNetRequest (to block filtered URLs), and offscreen (to run AI analysis in a background worker). No network or data-access permissions are needed.
